
# MakeTkinter (Windows)

Create your own interactive Python GUI programs using the build in library Tkinter. Remove the hassle of coding and use this new drag-and-drop system. This is the official repo containing releases, updates and more.


## Authors

- [@Ossie1011](https://github.com/Ossie1011)


## Installation

Download & Run:

```bash
  MakeTkinter.exe from Releases
```
